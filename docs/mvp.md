# MVP

The MVP supports:

1. CLI indexing for a Next.js App Router project.
2. Route tree discovery.
3. Page and component discovery.
4. Import graph construction.
5. Tailwind class extraction.
6. Repeated class group detection.
7. Basic component usage graph.
8. Local app shell with Exemplarium taxonomy.
9. Agent settings and safety contracts.
10. Storybook migration boundary without Storybook dependencies.

Deferred:

- Full preview runtime.
- Visual click-to-source overlay.
- AI-generated patches.
- Codemod execution.
- Storybook CSF import/export.
